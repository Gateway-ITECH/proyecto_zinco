=== FICHA TECNICA DE DOMINIOS INSTITUCIONALES, DNS Y CERTIFICADOS TLS ===
Proyecto: Plataforma Zinco (Ecosistema CTeI UNICOR)
Fecha: 2026-09-09

1. ESTRUCTURA DE DOMINIOS Y SUBDOMINIOS:
- Dominio Principal Institucional: unicordoba.edu.co
- Subdominio de Producción Plataforma Zinco: zinco.unicordoba.edu.co
- Subdominio de Staging / Pruebas: zinco-staging.unicordoba.edu.co
- Dominio de Desarrollo Local Contenerizado: zincowsl-app.lndo.site

2. REGISTRADOR Y TITULARIDAD:
- Registrador Oficial: .CO Internet S.A.S. (Administrador de ccTLD .co y .edu.co en Colombia)
- Titular Legal: Universidad de Córdoba (NIT 891.080.031-3)
- Estado de Delegación: Activo y delegado a los DNS institucionales

3. CONFIGURACIÓN DNS:
- Servidores DNS Autoritativos: ns1.unicordoba.edu.co, ns2.unicordoba.edu.co
- Registros Configurados:
  * zinco.unicordoba.edu.co. IN A <IP_PUBLICA_SERVIDOR_PRODUCCION>
  * zinco-staging.unicordoba.edu.co. IN A <IP_PUBLICA_SERVIDOR_STAGING>
  * TTL: 3600 segundos (1 hora)

4. CERTIFICADOS DIGITALES SSL / TLS:
- Tipo de Certificado: Certificado Wildcard TLS 1.3 (*.unicordoba.edu.co / zinco.unicordoba.edu.co)
- Autoridad Emisora (CA): Let's Encrypt / Autoridad de Certificación Institucional
- Algoritmo Criptográfico: RSA 4096 bits / SHA-256 con firmas seguras
- Mecanismo de Renovación: Daemon certbot automatizado cada 90 días con validación HTTP-01 / DNS-01
- Cabeceras de Seguridad: HSTS activo (Strict-Transport-Security), X-Frame-Options SAMEORIGIN
