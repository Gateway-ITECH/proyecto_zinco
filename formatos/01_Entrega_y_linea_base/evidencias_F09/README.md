# Carpeta de Evidencias Técnicas: F09 - Acta Reservada de Credenciales, Cuentas, Dominios y Titularidad

Esta carpeta contiene las evidencias técnicas, protocolos de custodia y constancias de transferencia formal de la **Plataforma Zinco** (Ecosistema CTeI UNICOR):

- `EVI-01_protocolo_custodia_seguridad/`: Protocolo de clasificación, custodia y traslado seguro de credenciales.
- `EVI-02_inventario_cuentas_privilegios/`: Inventario no secreto de cuentas, roles, servicios y políticas de autenticación MFA.
- `EVI-03_ficha_dominios_dns_tls/`: Ficha de titularidad de dominios *.unicordoba.edu.co, DNS y certificados TLS 1.3.
- `EVI-04_acta_transferencia_rotacion_secretos/`: Certificación de rotación previa de todos los secretos de producción.
- `EVI-05_certificado_revocacion_accesos/`: Certificado formal de revocación de accesos de desarrollo del proveedor.
- `EVI-06_constancia_entrega_recepcion/`: Constancia y acta de entrega-recepción formal entre Gateway IT S.A.S. y UNICOR.
- `MANIFEST_HASHES_SHA256.txt`: Hashes criptográficos SHA-256 de todas las evidencias.
