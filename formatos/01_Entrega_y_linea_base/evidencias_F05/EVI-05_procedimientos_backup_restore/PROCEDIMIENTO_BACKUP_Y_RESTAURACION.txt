=== PROCEDIMIENTO ESTANDARIZADO DE BACKUP Y RESTAURACIÓN MYSQL ===
Motor: MySQL 8.0 Community Server
Base de datos: drupal11
Prefijo de tablas: zinco_

1. COMANDO DE RESPALDO (BACKUP EN CALIENTE):
   mysqldump --single-transaction --quick --routines --triggers --events              -h database -u drupal11 -pdrupal11 drupal11 | gzip -9 > /app/backups/drupal11_$(date +%Y%m%d_%H%M%S).sql.gz

2. VERIFICACIÓN DE INTEGRIDAD DE RESPALDO:
   gzip -t /app/backups/drupal11_*.sql.gz && sha256sum /app/backups/drupal11_*.sql.gz

3. COMANDO DE RESTAURACIÓN:
   gunzip < /app/backups/drupal11_YYYYMMDD_HHMMSS.sql.gz | mysql -h database -u drupal11 -pdrupal11 drupal11

4. TIEMPOS OPERATIVOS:
   - Tiempo de generación de backup: < 1 minuto.
   - Tiempo de restauración: < 3 minutos.
   - RTO objetivo: < 15 minutos (comprobado en entorno Lando).
   - RPO objetivo: < 24 horas (ciclo de respaldo diario automatizado).
