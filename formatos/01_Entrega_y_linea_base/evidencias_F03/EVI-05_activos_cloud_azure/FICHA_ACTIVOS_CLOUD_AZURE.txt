=== FICHA DE ELEMENTOS DE CONFIGURACIÓN CLOUD: AZURE BLOB STORAGE ===
Activo: Contenedor Azure Blob Storage para Plataforma Zinco
Propósito: Persistencia y distribución desacoplada de documentos, evidencias de retos, fotos de actores y reportes generados en PDF.
Parámetros de configuración:
- Clave de configuración Drupal: zinco_etl.settings -> azure_blob_connection_string (Protegida)
- Contenedor de destino: zinco-files / reportes-pdf
- Protocolo de transporte: HTTPS TLS 1.3 / API REST Azure Blob v12
- Redundancia / Replicación: LRS (Locally-redundant storage)
- Mecanismo de prueba operativa: scripts/test_azure_connection.py
