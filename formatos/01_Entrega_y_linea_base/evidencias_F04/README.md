# Carpeta de Evidencias de Arquitectura As-Built — Formato F04

Esta carpeta contiene las evidencias técnicas, diagramas de arquitectura, matrices de seguridad e integraciones correspondientes al documento **Arquitectura As-Built (Formato F04)** de la **Plataforma Zinco**.

## Estructura de Evidencias

| Identificador | Descripción | Ubicación |
|---|---|---|
| **EVI-01** | Diagrama de arquitectura lógica multicapa (C4 Model y Mermaid) | `EVI-01_diagrama_arquitectura_logica/` |
| **EVI-02** | Diagrama de despliegue físico y topología de contenedores Lando | `EVI-02_diagrama_despliegue_fisico/` |
| **EVI-03** | Matriz de integraciones externas (Azure Blob, ScienTI/GrupLAC, SMTP) | `EVI-03_integraciones_y_protocolos/` |
| **EVI-04** | Matriz de seguridad, zonas de confianza y controles RBAC | `EVI-04_seguridad_zonas_de_confianza/` |
| **EVI-05** | Plan de continuidad operativa, disponibilidad y métricas RTO/RPO | `EVI-05_continuidad_y_respaldo/` |
| **EVI-06** | Catálogo de interfaces, endpoints y rutas del módulo `zinco_front` | `EVI-06_inventario_interfaces_endpoints/` |
