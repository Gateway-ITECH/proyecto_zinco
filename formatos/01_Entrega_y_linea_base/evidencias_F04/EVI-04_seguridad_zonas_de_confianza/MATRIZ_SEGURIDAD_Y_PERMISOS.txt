=== MATRIZ DE SEGURIDAD, ZONAS DE CONFIANZA Y CONTROL DE ACCESO ===
Proyecto: Plataforma Zinco (Ecosistema CTeI UNICOR)

1. ZONAS DE CONFIANZA:
   - Zona Pública (DMZ): Acceso sin autenticar. Landing page (/landing), consulta de actores y catálogo de retos.
   - Zona Autenticada: Acceso mediante login por roles (/dashboard, postulación a soluciones, perfil de actor).
   - Zona de Administración Restringida: Exclusiva para rol 'administrator' (/admin, gestión de taxonomías y configuraciones).
   - Zona de Datos Aislada: Base de datos MySQL y almacenamiento Azure no accesibles de forma directa desde internet.

2. CONTROLES DE SEGURIDAD IMPLEMENTADOS:
   - Control de Acceso por Roles (RBAC): Matriz de permisos de Drupal 11 con 8 roles institucionales:
     * investigador, empresa_generadora_de_conocimiento, empresa_explotadora_de_conocimiento,
     * institucion_de_educacion_superior, entidad_gobierno, parque_tecnologico,
     * content_editor, administrator.
   - Protección contra CSRF: Validación de tokens criptográficos en todos los envíos de formularios (Form API).
   - Prevención de XSS: Sanitización automática y autoescape de variables mediante el motor Twig.
   - Prevención de SQL Injection: Consultas parametrizadas obligatorias a través de la API de Base de Datos de Drupal (PDO).
   - Gestión Segura de Secretos: Parámetros de base de datos y llaves Azure excluidas de control de versiones y custodiadas en settings.php y variables de entorno.
   - Auditoría y Logs: Trazabilidad integral en Drupal Watchdog de inicios de sesión, cambios de estado y excepciones.
