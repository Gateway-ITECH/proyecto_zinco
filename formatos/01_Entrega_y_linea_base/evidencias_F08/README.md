# Carpeta de Evidencias Técnicas: F08 - Licencias, Dependencias, Terceros y SBOM

Esta carpeta contiene las evidencias técnicas, manifiestos de software de terceros y el SBOM formal de la **Plataforma Zinco** (Ecosistema CTeI UNICOR):

- `EVI-01_catalogo_dependencias_licencias/`: Catálogo con las 113 librerías PHP de producción, versiones y licencias.
- `EVI-02_sbom_cyclonedx_spdx/`: SBOM formal estandarizado en formato CycloneDX 1.5 JSON (138 componentes).
- `EVI-03_matriz_ciclo_vida_eol_eos/`: Matriz de fin de soporte (EOL/EOS) para Drupal 11, PHP 8.4, MariaDB y Dompdf.
- `EVI-04_reporte_vulnerabilidades_sca/`: Reporte de análisis de vulnerabilidades sobre dependencias congeladas.
- `EVI-05_ficha_renovaciones_cloud/`: Ficha de suscripción Azure Blob Storage, dominios institucionales y certificados SSL.
- `EVI-06_evidencia_titularidad/`: Evidencia de cesión de derechos patrimoniales y compatibilidad legal de software libre.
- `MANIFEST_HASHES_SHA256.txt`: Hashes criptográficos SHA-256 de todas las evidencias.
