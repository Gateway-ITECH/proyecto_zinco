=== MATRIZ DE CICLO DE VIDA, FIN DE SOPORTE (EOL / EOS) Y ACTUALIZACIONES ===
Proyecto: Plataforma Zinco (Ecosistema CTeI UNICOR)
Fecha de evaluación: 2026-09-09

1. COMPONENTES PRINCIPALES Y CICLO DE VIDA:
- Drupal Core 11.3.3:
  * Lanzamiento: 2024
  * Soporte Activo: Vigente
  * Fin de Soporte proyectado (EOL): ~Q4 2028 (al lanzamiento de Drupal 13)
  * Nivel de Riesgo: Bajo (en ciclo de vida inicial y estable)

- PHP 8.4:
  * Lanzamiento: Noviembre 2024
  * Soporte Activo: Hasta Noviembre 2026
  * Fin de Soporte de Seguridad (EOL): Noviembre 2028
  * Nivel de Riesgo: Muy Bajo

- MariaDB 8.0 / MySQL 8.0 LTS:
  * Soporte Activo y de Seguridad: Vigente hasta 2029
  * Nivel de Riesgo: Bajo

- Dompdf 3.1.4:
  * Versión actual compatible plenamente con PHP 8.4
  * Mantenimiento de parches: Activo por el equipo Dompdf en GitHub
  * Nivel de Riesgo: Bajo

- Apache HTTP Server 2.4.x:
  * Servidor web de grado industrial con soporte LTS continuo
  * Nivel de Riesgo: Muy Bajo

2. PLAN DE ACTUALIZACIÓN Y PARCHEO:
- Auditoría semestral con 'composer outdated' y 'composer audit'.
- Parcheo inmediato de vulnerabilidades calificadas como CRITICAL o HIGH en Drupal Security Advisories.
- Pruebas en ambiente de Staging de UNICOR antes de promover a Producción.
