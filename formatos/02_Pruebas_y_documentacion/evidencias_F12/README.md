# Carpeta de Evidencias Técnicas: F12 - Registro de Ejecución de Pruebas y UAT

Esta carpeta contiene las evidencias técnicas de ejecución de pruebas, gestión de defectos y constancia de aceptación en Staging de la **Plataforma Zinco** (Ecosistema CTeI UNICOR):

- `EVI-01_plan_bitacora_sesiones_pruebas/`: Plan y bitácora de las sesiones de pruebas unitarias y funcionales.
- `EVI-02_log_ejecucion_casos_prueba/`: Log de ejecución de casos de prueba sobre los 12 módulos funcionales.
- `EVI-03_registro_defectos_y_repruebas/`: Registro de defectos detectados, correcciones y repruebas de no regresión.
- `EVI-04_constancia_no_aplica_ambiente_uat/`: Constancia institucional formalizando la inexistencia de ambiente UAT dedicado y la ejecución equivalente en Staging.
- `EVI-05_reporte_rendimiento_seguridad/`: Reporte de pruebas no funcionales de latencia, seguridad y no regresión.
- `EVI-06_acta_cierre_pruebas_staging/`: Acta formal de cierre y conformidad de pruebas emitida conjuntamente con UNICOR.
- `MANIFEST_HASHES_SHA256.txt`: Hashes criptográficos SHA-256 de todas las evidencias.
